# Wild Atlas

A substantial wildlife education frontend intended to be handed from an application-development team to a DevOps/platform workflow.

## Application scope
- React + Vite frontend
- Responsive editorial wildlife design
- 12 detailed animal profiles
- Species search
- Interactive species profile modal
- Habitat exploration
- Conservation section
- External photographic assets from Unsplash

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Application port
Vite development server defaults to `5173`.

## DevOps handoff
This repository intentionally does **not** contain Jenkins, Terraform, Kubernetes, Helm, Argo CD, cloud infrastructure, or deployment configuration. Those are left for the infrastructure/delivery exercise.
